Kirit Foundry Managed Agent — Lab Developer

This site describes a privately operated educational proof of concept that connects a Microsoft Foundry AI agent with Microsoft Teams and Microsoft 365 Copilot. The app is named Kirit Foundry Managed Agent.

The purpose is to test a managed Teams bot registration without deploying a customer-owned Azure Bot Service resource.

The agent's replies are AI-generated. This site is not affiliated with or endorsed by Microsoft.
